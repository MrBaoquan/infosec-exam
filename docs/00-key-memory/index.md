# 🎯 重点记忆篇章

> 这一篇只放**一件东西**：我原本不熟悉、需要真正学会的题型的**解题思路**。
> 不是知识点汇编，而是「拿到这类题，第一步做什么、第二步做什么」的可执行流程。

## 为什么单独开这一篇

| 普通考点笔记 | 重点记忆篇章 |
|--------------|--------------|
| 按大纲章节讲知识 | 按**题型**讲打法 |
| 追求覆盖全面 | 只收我**没掌握**的 |
| 读懂了 ≠ 会做 | 目标是**照着步骤能算出答案** |
| 复习时翻整章 | 复习时只看口诀卡 |

## 使用方法（三步复习法）

1. **第一遍 · 读步骤**：只看「通用解题步骤」和「例题解答」，跟着算一遍，确保每一步都懂。
2. **第二遍 · 遮答案自测**：跳到「变式训练」，先自己写在纸上，再展开折叠的答案对照。
3. **第三遍 · 背口诀卡**：考前只复习每页最后的「考点速记卡」，口诀能复述 = 这题型过关。

> 页面右下角的浮动按钮可以标记「未学 / 学习中 / 已掌握」，进度存在本机，手机上也能用。

## 实战演练与薄弱点台账

题型页讲「这类题怎么答」，台账记「我每次错在哪」，两者配合用。

| 页面 | 用途 | 怎么用 |
|------|------|--------|
| [简答题实战演练与薄弱点台账](/docs/key-memory/short-answer-drill) | 一轮一题、逐点给分，失分点汇总成考前清单 | 每天做 1–2 题，考前只看「复习清单」一节 |

> 阅读顺序建议：先看台账里自己失分过的考点 → 再看对应题型页的通用步骤 → 回台账做变式题复查。

## 新增题型的约定（长期规则）

每当探讨一个新的、我不熟悉的题型，就按下面这套动作沉淀，**不跳过任何一步**：

1. 在 `docs/00-key-memory/` 下新建一个题型页（一题型一页，旧的只做增补不覆盖）。
2. 每个题型页必须写满七块内容：
   **识别信号 → 核心原理 → 通用解题步骤 → 本次例题完整解答 → 变式训练 → 易错点 → 考点速记卡**。
3. 回到本页更新「题型索引」表格。
4. 同步更新侧边栏 → `npm run build` 验证通过 → 提交推送，自动发布到线上。
