# 题型 01 · IP 子网划分与子网地址计算

> **本次原题**：假定一台主机的 IP 地址为 180.120.74.56，子网掩码为 255.255.240.0，则该子网地址为 \_\_\_\_\_\_。
> **答案**：**180.120.64.0**

## 一、识别信号（看到这些就是这类题）

- 题干同时给了 **IP 地址** 和 **子网掩码**，问「子网地址 / 网络地址 / 网络号」。
- 问「广播地址」「地址范围」「第一个/最后一个可用地址」。
- 问「可用主机数」「最多能接多少台主机」。
- 问「这两台主机是否在同一子网」「属于哪个网段」。
- 问「要划分 N 个部门，掩码应该填什么」「要容纳 M 台主机，掩码填什么」。
- 题干只给 `/20` 这种**前缀长度**，不给点分十进制掩码 —— 同一个知识点的两种写法而已。

**考试定位**：上午选择题里通常 1~3 分（「计算机网络」板块的常客）；下午网络安全配置大题里，也可能要求你在拓扑图的空白处填子网地址或掩码。

## 二、核心原理（3 分钟真正搞懂）

### 1. 掩码的全部作用：把 IP 切成「网络位 + 主机位」

```
255.255.240.0  =  11111111.11111111.11110000.00000000
                  └──── 网络位 20 位 ────┘└ 主机位 12 位 ┘
```

- **连续的 1** 覆盖的比特 = **网络位**（属于哪个子网，由它决定）。
- **连续的 0** 覆盖的比特 = **主机位**（子网内的编号，由它决定）。
- 1 的总个数就是**前缀长度**，写成 `/20`。

### 2. 子网地址是怎么来的

:::tip 一句话本质
**子网地址 = IP 地址 与 子网掩码 做「按位与（AND）」。**

按位与的规则：`1 AND x = x`，`0 AND x = 0`。
所以：掩码是 1 的位 → 保留（抄 IP）；掩码是 0 的位 → 全部清零。
:::

这就解释了为什么算出来的子网地址，**末尾那个字节几乎总是 0** —— 因为掩码那里是 0，全被清零了。

### 3. 两个必须记住的换算

| 概念 | 算法 | 本题数据 |
|------|------|----------|
| 前缀长度 | 掩码中和 1 的个数 | `/20`（16 + 4） |
| **关键字节** | 掩码中**最左边那个值不是 255 的字节** | 第 3 字节，值 240 |
| **块大小** | 256 − 关键字节的掩码值 | 256 − 240 = **16** |
| 主机位位数 | 32 − 前缀长度 | 32 − 20 = **12** |

关键字节是整套算法的**抓手**：子网的边界就是靠它按「块大小」切出来的。

## 三、通用解题步骤（照着套，五步）

> 适用范围：任何「给 IP + 掩码，求子网地址」的题，不管掩码是 `/16` 还是 `/30`。

1. **写出掩码，找出关键字节**：从左往右看四个字节，**第一个值不是 255 的字节**就是关键字节。
   （例：255.255.240.0 → 第 3 字节 240；255.255.255.0 → 第 4 字节 0，块大小 = 256 − 0 = 256，效果正是把该字节清零，与第 4 步自洽。）
2. **算块大小**：块大小 = 256 − 关键字节的掩码值。
3. **算该字节的块起点**：用 IP 在**同一字节**上的值 ÷ 块大小，**向下取整**，再 × 块大小。
4. **拼出子网地址**：关键字节**之前**的字节照抄 IP，关键字节用第 3 步的结果，关键字节**之后**的字节全部写 0。
5. **按需扩展**：广播地址 = 块起点 + 块大小 − 1（后续字节写 255）；可用主机数 = $2^{n}-2$（n = 主机位位数）。

## 四、本题完整解答

**题目**：IP = 180.120.74.56，掩码 = 255.255.240.0，求子网地址。

### 步骤 1 · 掩码拆成二进制，找关键字节

```text
掩码 : 255      .255      .240      .0
二进制: 11111111 .11111111 .11110000 .00000000
                    ↑
             第 3 字节 = 240，非 255 非 0 → 关键字节
```

前缀长度 = 8 + 8 + 4 + 0 = **/20**。

### 步骤 2 · 算块大小

```text
块大小 = 256 − 240 = 16
```

意思是：第 3 字节上，子网只能落在 0、16、32、48、64、80 …… 这些边界上。

### 步骤 3 · 算 IP 第 3 字节落在哪个块

```text
74 ÷ 16 = 4 …… 余 10      （74 = 4×16 + 10）
向下取整得 4  →  4 × 16 = 64
```

所以第 3 字节的块起点是 **64**，本子网的第 3 字节范围是 **64 ~ 79**（64 + 16 − 1 = 79）。
74 确实落在 64~79 之间 ✔

### 步骤 4 · 按位与验证（考试可直接心算，这里给全过程）

```text
IP   : 180      .120      .74       .56
       10110100 .01111000 .01001010 .00111000
MASK : 11111111 .11111111 .11110000 .00000000
       ────────────────── AND ──────────────────
结果 : 10110100 .01111000 .01000000 .00000000
       180      .120      .64       .0
```

逐字节核对：

| 字节 | IP | 掩码 | 运算 | 结果 |
|:----:|:--:|:----:|------|:----:|
| 1 | 180 | 255 | 255 全 1，照抄 | **180** |
| 2 | 120 | 255 | 255 全 1，照抄 | **120** |
| 3 | 74 | 240 | 74 AND 240 = 64 | **64** |
| 4 | 56 | 0 | 掩码全 0，清零 | **0** |

### 步骤 5 · 结论与完整结果簇

> ✅ **子网地址（网络地址）= 180.120.64.0**

顺手把这一族常考数据一次算全：

| 项目 | 结果 | 算法 |
|------|------|------|
| 子网地址 | **180.120.64.0** | IP AND 掩码 |
| 网络前缀 | **180.120.64.0/20** | 前缀长度 20 |
| 广播地址 | **180.120.79.255** | 第 3 字节 64+16−1 = 79，第 4 字节 255 |
| 可用地址范围 | **180.120.64.1 ~ 180.120.79.254** | 首尾各去掉一个 |
| 地址总数 | $2^{12}$ = **4096** 个 | 主机位 12 位 |
| 可用主机数 | $2^{12}-2$ = **4094** 台 | 去掉网络地址和广播地址 |
| 下一个子网 | **180.120.80.0** | 64 + 16 = 80 |

## 五、变式训练（先自己做，再展开答案）

:::note 自测方法
拿纸写下答案，再点开下面对应条目的三角标对照。**做错的那一条，回到第三节重走一遍步骤。**
:::

<details>
<summary><b>变式 1</b>：该主机的广播地址是多少？</summary>

**180.120.79.255**

第 3 字节块起点 64，块大小 16 → 64 + 16 − 1 = 79；主机位所在的第 4 字节全部置 1 → 255。

</details>

<details>
<summary><b>变式 2</b>：该子网最多能接多少台主机？</summary>

**4094 台**

前缀 /20 → 主机位 = 32 − 20 = 12 位 → 地址总数 $2^{12}$ = 4096；减去网络地址和广播地址两个不可用 → 4094。

（口诀：可用主机数 = $2^{n}-2$，n 是主机位位数。）

</details>

<details>
<summary><b>变式 3</b>：180.120.74.56 与 180.120.80.10 是否在同一子网？</summary>

**不在同一子网。**

掩码相同，所以只看关键字节：
- 74 落在 **64~79** 块 → 子网 180.120.64.0
- 80 落在 **80~95** 块 → 子网 180.120.80.0

两台主机跨子网通信必须经过路由器（网关）。这正是「同子网判断」题的通用打法：**分别求子网地址，相等才同网。**

</details>

<details>
<summary><b>变式 4</b>：掩码 255.255.255.224 对应的前缀长度、块大小、可用主机数？</summary>

- 前缀长度：8+8+8+3 = **/27**（224 = 11100000，3 个 1）
- 关键字节：第 4 字节 224 → 块大小 = 256 − 224 = **32**
- 主机位 = 32 − 27 = 5 → 可用主机数 = $2^{5}-2$ = **30 台**

</details>

<details>
<summary><b>变式 5</b>：某部门有 50 台主机，掩码应填什么？（要求不浪费地址）</summary>

**255.255.255.192（/26）**

推法：$2^{n}-2 \ge 50$ → $2^{5}-2 = 30$ 不够，$2^{6}-2 = 62$ 够 → 主机位 6 位 → 前缀 = 32 − 6 = **/26** → 掩码 = 255.255.255.192，块大小 64，每段可用 62 个地址。

（这是「反向设计题」：**先定主机位，再反推掩码**。）

</details>

<details>
<summary><b>变式 6</b>：若把掩码写成反掩码（ACL wildcard），应该是什么？</summary>

**0.0.15.255**

反掩码 = 掩码按位取反：255.255.240.0 → 0.0.15.255。

注意方向**反过来**：反掩码里 0 表示「必须匹配」，1 表示「忽略」。防火墙/ACL 配置题常在这里设坑。

</details>

## 六、易错点与陷阱

| 陷阱 | 错误做法 | 正确做法 |
|------|----------|----------|
| **把 240 当块大小** | 用 74 ÷ 240 | 块大小 = 256 − 240 = **16** |
| **把非关键字节清零** | 得到 0.0.64.0 | 前两个 255 字节**照抄 IP** → 180.120.64.0 |
| **前缀长度算成 /24** | 看到 255 就加 8 | 240 = 11110000 → 只有 **4** 个 1 → /20 |
| **忘记减 2** | 可用主机数答 4096 | 减去网络地址 + 广播地址 → **4094** |
| **广播地址末字节写 56** | 180.120.79.56 | 主机位全 1 → **180.120.79.255** |
| **混淆网络地址与网关** | 把 180.120.64.0 当网关 | 网络地址不可分配给主机；网关通常是**第一个可用地址** 180.120.64.1 |
| **同子网只看 IP 前缀** | 肉眼看「180.120 一样就是同网」 | 必须**用掩码算子网地址**再比 |
| **/30 与 /31 特例** | 一律减 2 | /30 可用 2 个（点对点链路）；/31（RFC 3021）可用 2 个、无网络/广播地址 |

:::caution 最值钱的一条
**块大小 = 256 − 关键字节**。这一条能让你 10 秒内定位子网边界，比每次画二进制快得多，而且不容易错。
:::

## 七、考点速记卡（复习只看这一块）

### 口诀

> **子网地址 = IP 与掩码按位与；块大小 = 256 − 关键字节；起点向下取整到块边界；网络位照抄、主机位清零。**

### 三步心算模板

```text
① 找关键字节（掩码里非 255 非 0 的那个）
② 块大小 = 256 − 该字节掩码值
③ 起点 = IP 该字节 ÷ 块大小（取整）× 块大小
   前照抄、后清零 → 子网地址
   起点 + 块大小 − 1 → 广播地址
```

### 常用掩码对照表（背下来，考场上直接取用）

| 前缀 | 掩码 | 关键字节块大小 | 可用主机数 |
|:----:|------|:--------------:|:----------:|
| /24 | 255.255.255.0 | 256 | 254 |
| /25 | 255.255.255.128 | 128 | 126 |
| /26 | 255.255.255.192 | 64 | 62 |
| /27 | 255.255.255.224 | 32 | 30 |
| /28 | 255.255.255.240 | 16 | 14 |
| /29 | 255.255.255.248 | 8 | 6 |
| /30 | 255.255.255.252 | 4 | 2 |
| **/20** | **255.255.240.0** | **16** | **4094** |

### 通用公式（n = 主机位位数，k = 向主机位借的位数）

- 地址总数 = $2^{n}$，其中 **n = 32 − 前缀长度**
- 可用主机数 = $2^{n}-2$（减去网络地址与广播地址）
- 子网个数（相对该类地址的默认掩码）= $2^{k}$
